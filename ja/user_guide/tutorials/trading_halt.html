売買停止¶

売買停止（サーキットブレーカー）は、市場の価格が大きく動きすぎたときに、その市場の取引をしばらく止めます。このチュートリアルは、Plhamのチュートリアル TradingHaltMain と TradingHaltMain_UseCases に沿っています：ファンダメンタル価格が10%下落し、市場は売買停止なし、売買停止あり、より長い売買停止、より低い閾値のそれぞれでこれに追随します。完全なスクリプトは tutorial_trading_halt.py です。プロットには matplotlib が必要ですが、これはPAMSと一緒にはインストールされません（pip install matplotlib）。

モデル¶

市場には100体の FCNAgent エージェントがいます。各エージェントは、ファンダメンタル価格との乖離、直近のトレンド、ノイズから将来の価格を予想し、その価格の周りに注文を出します。ステップ100で、FundamentalPriceShock がファンダメンタル価格を300から270に下げます。するとエージェントは売り、市場価格は270に向かって下がります。

TradingHaltRule は、約定のたびに市場価格 \(P\) を調べます。ステップ0の市場価格を \(P_0\)、率 triggerChangeRate を \(r\)、それまでの売買停止の回数を \(n\) とします。次の式が成り立つと、

\[|P - P_0| \geq P_0 \, r \, (n + 1),\]

ルールは対象のすべての市場で売買を停止します。売買停止中の市場は、注文や取消を受け付けますが、何も約定しないため、価格は変わりません。\(L\) を haltingTimeLength とすると、ステップ \(s\) に始まった売買停止はステップ \(s + L\) の終わりまで続き、市場はステップ \(s + L + 1\) から再び取引を行います。

ここでは \(P_0 = 300\) です。\(r = 0.05\) では、1回目の売買停止は価格が5%動いたとき（285または315）、2回目は10%動いたとき（270または330）に起こり、以下同様です。

Plhamのチュートリアルは3つの問いを立てています：ショックの後に売買停止が何をするか、より長い売買停止が何をするか、そしてより低い閾値が何をするかです。

設定¶

設定は、リポジトリの samples/trading_halt/config.json から MEMO キーを除き、Pythonのdictとして書いたものです：

CONFIG: Dict[str, Any] = {
    "simulation": {
        "markets": ["Market"],
        "agents": ["FCNAgents"],
        "sessions": [
            {
                "sessionName": 0,
                "iterationSteps": 100,
                "withOrderPlacement": True,
                "withOrderExecution": False,
                "withPrint": True,
            },
            {
                "sessionName": 1,
                "iterationSteps": 500,
                "withOrderPlacement": True,
                "withOrderExecution": True,
                "withPrint": True,
                "events": ["FundamentalPriceShock", "TradingHaltRule"],
            },
        ],
    },
    "FundamentalPriceShock": {
        "class": "FundamentalPriceShock",
        "target": "Market",
        "triggerTime": 0,
        "priceChangeRate": -0.1,
        "enabled": True,
    },
    "TradingHaltRule": {
        "class": "TradingHaltRule",
        "targetMarkets": ["Market"],
        "triggerChangeRate": 0.05,
        "haltingTimeLength": 100,
        "enabled": True,
    },
    "Market": {
        "class": "Market",
        "tickSize": 0.00001,
        "marketPrice": 300.0,
        "outstandingShares": 25000,
    },
    "FCNAgents": {
        "class": "FCNAgent",
        "numAgents": 100,
        "markets": ["Market"],
        "assetVolume": 50,
        "cashAmount": 10000,
        "fundamentalWeight": {"expon": [1.0]},
        "chartWeight": {"expon": [0.0]},
        "noiseWeight": {"expon": [1.0]},
        "noiseScale": 0.001,
        "timeWindowSize": [100, 200],
        "orderMargin": [0.0, 0.1],
    },
}

  • 最初のセッション（ステップ0から99）は板を埋めるだけです。2番目のセッション（ステップ100から599）では注文の約定も行い、その events に両方のイベントを列挙しています。

  • triggerTime はイベントを列挙したセッションの開始から数えるため、ショックはステップ100に起こります。

  • ファンダメンタル成分の重みの平均は1.0、チャート成分の重みの平均は0なので（ランダムパラメータ（JsonRandom） を参照）、エージェントはファンダメンタル価格に引き寄せられ、トレンド追随型のエージェントはいません。

各キーの説明は イベント と エージェント にあります。

スクリプトは4つのケースを比較します。これらのケースでは、閾値、売買停止の長さ、ルールを有効にするかどうかを変えます：

# the threshold, the length of a halt and whether the rule is on
CASES: Dict[str, Tuple[float, int, bool]] = {
    "halt 5%, 100 steps": (0.05, 100, True),
    "no halt": (0.05, 100, False),
    "halt 5%, 200 steps": (0.05, 200, True),
    "halt 2%, 100 steps": (0.02, 100, True),
}

実行¶

run_simulation は、設定のコピーについてこれらの値と、2番目のセッションの長さを変更します：

def run_simulation(
    seed: int,
    rate: float = 0.05,
    length: int = 100,
    enabled: bool = True,
    main_steps: int = 500,
) -> Tuple[SequentialRunner, HaltRecorder]:
    """Run the simulation with the given trading halt rule.

    Args:
        seed (int): seed of the random number generator.
        rate (float): threshold ``triggerChangeRate`` of the rule.
        length (int): length ``haltingTimeLength`` of a halt.
        enabled (bool): whether the rule is on.
        main_steps (int): number of steps of the main session.

    Returns:
        Tuple[SequentialRunner, HaltRecorder]: the runner after the run and the
        recorder of the halted steps.

    """
    config = copy.deepcopy(CONFIG)
    config["TradingHaltRule"]["triggerChangeRate"] = rate
    config["TradingHaltRule"]["haltingTimeLength"] = length
    config["TradingHaltRule"]["enabled"] = enabled
    config["simulation"]["sessions"][1]["iterationSteps"] = main_steps
    recorder = HaltRecorder()
    runner = SequentialRunner(
        settings=config, prng=random.Random(seed), logger=recorder
    )
    # main() prints the time taken, which is not needed here
    with contextlib.redirect_stdout(io.StringIO()):
        runner.main()
    return runner, recorder

"enabled": False のルールは何もしません。それでも乱数は引くため、ルールを無効にした実行は、最初の売買停止まで、ルールを有効にした実行と同じになります。

ルールは売買停止の回数を activation_count に数えますが、売買停止したステップは記録しません。そこでロガー（ロガーの作成 を参照）がそれを記録します：各ステップの終わりに、売買停止中の市場では market.is_running が False になります。

class HaltRecorder(Logger):
    """Record the steps at whose end the market is halted."""

    def __init__(self) -> None:
        """Initialize the recorder."""
        super().__init__()
        self.halted: List[int] = []

    def process_market_step_end_log(self, log: MarketStepEndLog) -> None:
        """Keep the step if the market is not running at its end.

        Args:
            log (MarketStepEndLog): the log of the end of a market step.

        """
        # in a session without order execution, the market never runs
        if log.session.with_order_execution and not log.market.is_running:
            self.halted.append(log.market.get_time())

halt_starts は、これらのステップから各売買停止の最初のステップを見つけます。1回の売買停止は \(L + 1\) 個のステップの終わりにわたるため、それより後の売買停止中のステップは新しい売買停止に属します：

def halt_starts(halted: List[int], length: int) -> List[int]:
    """Find the steps at which the halts start.

    A halt that starts at step ``s`` covers the ends of the steps ``s`` to
    ``s + length``, so a halted step after them belongs to a new halt.

    Args:
        halted (List[int]): the halted steps, in order.
        length (int): length ``haltingTimeLength`` of a halt.

    Returns:
        List[int]: the first step of each halt.

    """
    starts: List[int] = []
    for time in halted:
        if len(starts) == 0 or time > starts[-1] + length:
            starts.append(time)
    return starts

halt_stats は1回の実行を集計します：売買停止の回数、売買停止中のステップ数、各売買停止の最初のステップ、2番目のセッションにおける市場価格の最安値と最終値、そしてその間に取引された株数です。無効なイベントは simulator.name2event に追加されないため、ルールのない実行では売買停止は0回になります：

def halt_stats(runner: SequentialRunner, recorder: HaltRecorder) -> Dict[str, Any]:
    """Summarize the halts and the prices of the main session.

    Args:
        runner (SequentialRunner): the runner after the run.
        recorder (HaltRecorder): the recorder used as the logger of the run.

    Returns:
        Dict[str, Any]: the number of halts, the number of halted steps, the first
        step of each halt, the lowest and the last market prices, and the number
        of shares traded.

    """
    market = runner.simulator.name2market["Market"]
    main_session = runner.simulator.sessions[1]
    start = main_session.session_start_time
    times = range(start, start + main_session.iteration_steps)
    prices: List[float] = market.get_market_prices(times=times)
    # a disabled event registers no hooks and is not in name2event
    event = runner.simulator.name2event.get("TradingHaltRule")
    halts = 0
    starts: List[int] = []
    if isinstance(event, TradingHaltRule):
        halts = event.activation_count
        starts = halt_starts(recorder.halted, event.halting_time_length)
    return {
        "halts": halts,
        "halted": len(recorder.halted),
        "starts": starts,
        "lowest": min(prices),
        "last": prices[-1],
        "traded": sum(market.get_executed_volumes(times=times)),
    }

ショック後の売買停止¶

スクリプトはまず、シード42で4つのケースを実行します。出力は次のとおりです：

case                halts  halted  lowest    last  traded  halt starts
halt 5%, 100 steps      2     202  260.91  267.66     191  127, 275
no halt                 0       0  259.92  279.38     215  -
halt 5%, 200 steps      2     402  266.82  271.17     148  127, 379
halt 2%, 100 steps      5     476  268.97  268.97     141  111, 212, 313, 414, 528

図は4つのケースの価格を示しており、売買停止の期間は網掛けになっています：

5%で100ステップの売買停止の場合（1行目と最初のパネル）：

  • ショックの後、価格は下がります。ステップ127で、300より5.4%低い283.71での約定が、1回目の売買停止を引き起こします。

  • 市場はステップ228から再び取引を行います。売買停止中に出された注文はすぐに約定します：このステップで27株が約定し、価格は278.64に動きます。

  • ステップ275で、300より10.0%低い269.95での約定が、2回目の売買停止を引き起こします。その後、ステップ376で24株がすぐに約定します。3回目の売買停止には255までの15%の下落が必要ですが、これは起こりません。

  • 市場は500ステップのうち202ステップの終わりで売買停止中です：101ステップの売買停止が2回です。

売買停止なし（2行目）の場合、実行はステップ127まで同じです。その後、価格は新しいファンダメンタル価格を下回ってステップ213で259.92になり、279.38で終わります。この実行では、売買停止は最安値をほとんど変えません（259.92に対して260.91）。後に示す他のシードでの実行では、よりはっきりした違いが見られます。

より長い売買停止¶

Plhamのチュートリアルは、次に売買停止を200ステップにします。売買停止の効果は、その長さがエージェントの時間窓と比べてどうかによるはずです。時間窓は100から200ステップの間なので、200ステップはそのどれよりも長くなります。PAMSでも、FCNエージェントの注文はその時間窓と同じステップ数だけ板に残るため、200ステップの売買停止の前に出された注文は、市場が再び取引を行うときには残っていません。

200ステップの場合（3行目と3番目のパネル）、売買停止はステップ127と379に始まり、市場は500ステップのうち402ステップで売買停止中です。最安値は266.82で、最初の2つのケースより270に近くなりますが、取引されるのは148株だけで、売買停止なしでは215株です。

より低い閾値¶

最後に、Plhamのチュートリアルは閾値を下げます。ショックは10%なので、閾値が2%であれば、価格がショックに追随する間にルールは市場の売買を何度か停止できます。2%の場合（最後の行と最後のパネル）、売買停止は2%、4%、6%、8%、10%の変動で起こり、市場はステップ111、212、313、414、528の5回売買停止します。

ステップ212、313、414の売買停止が、市場が再び取引を行うステップに始まるのには、2つの理由があります。

  • ステップ212では、最初の売買停止中に出された注文がすぐに約定します。このジャンプで、価格は291.28（300より2.9%低い）から281.33（6.2%低い）に動き、4%の閾値を超えます。

  • ステップ313と414では、市場が再び取引を行うときには、価格はすでに次の閾値を超えています。281.33は6%を超えており、ステップ313からの価格である275.48は8%を超えています。これらのステップの取引では価格が戻らないため、市場はすぐにまた売買停止になります。

市場は500ステップのうち476ステップの終わりで売買停止中で、価格は階段状に下がります。最後の売買停止は実行の終わりまで続くため、最終値は最安値でもあり、268.97です。

10個のシードでの比較¶

スクリプトは4つのケースをシード42から51で繰り返し、平均を出力します：

case                halts  halted  lowest    last  traded
halt 5%, 100 steps    2.0   202.0  258.79  265.60   191.3
no halt               0.0     0.0  251.19  268.07   216.0
halt 5%, 200 steps    2.0   399.7  265.61  268.66   136.3
halt 2%, 100 steps    5.0   472.0  268.90  268.90   136.1

  • どのシードでも、5%では売買停止が2回、2%では5回です。

  • 平均すると、売買停止は最安値を引き上げます：最安値の平均は、売買停止なしで251.19、100ステップの売買停止で258.79、200ステップの売買停止で265.61、2%の閾値で268.90です。

  • 売買停止によって、最終値が新しいファンダメンタル価格である270に近づくわけではありません：最終値の平均は、100ステップの売買停止で265.60、売買停止なしで268.07です。

  • 最初の2つのケースの違いは、主に2つのシードによるものです。売買停止なしの場合、最安値はシード46で229.1、シード47で221.1です。他の8個のシードでは255から260の間で、100ステップの売買停止での最安値（255から262）に近い値です。

  • 売買停止には取引時間という代償があります。売買停止ありの3つのケースでは、市場は2番目のセッションのそれぞれ約40%、80%、94%で売買停止中であり、取引される株数も少なくなります。

  • 売買停止中の市場は取引できないため、下落することもできません。2%の閾値では、価格はほとんどの時間止まっており、その最安値は市場がどう動くかをほとんど示しません。

スクリプトの実行¶

完全なスクリプトを python tutorial_trading_halt.py で実行すると、上の2つの表を出力し、カレントディレクトリに trading_halt_prices.png を書き出します。600ステップのシミュレーションを44回実行します。

値幅制限は、市場を開いたまま、代わりに注文の価格を動かします：値幅制限 を参照してください。

Plhamとの違い¶

  • Plhamは基準価格を参照市場から取ります。PAMSは各市場を、それ自身のステップ0の価格（この価格は変わりません）と比べ、古い設定にある referenceMarket キーは警告を出したうえで無視します。

  • 上の数値はシード42から51でのPAMSの結果で、Plhamのチュートリアルの図とは一致しません。
