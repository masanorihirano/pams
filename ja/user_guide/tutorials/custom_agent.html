エージェントの作成¶

このチュートリアルでは、2つのエージェントを作成し、シミュレーションの実行 のシミュレーションに追加します：

  • MovingAverageAgent：Agent から作成する新しい戦略。

  • ContrarianFCNAgent：FCNAgent に小さな変更を加えたもの。

完全なスクリプトは tutorial_custom_agent.py です。

ランナーによるエージェントの扱い¶

ランナーは、設定の各エージェントについて次のことを行います：

  1. agent_id、name （"MovingAverageAgents-0" など）、simulator、logger、および各自の乱数生成器 prng を与えてエージェントを作成します。__init__ を変更する必要はほとんどありません。

  2. すべての市場とエージェントが作成された後に、setup(settings, accessible_markets_ids) を1回呼び出します。settings は設定におけるそのエージェントのブロックで、extends を解決した後の内容から numAgents、from、to、prefix を除いたものです。グループのすべてのエージェントが同じdictを受け取るため、読み取るだけにして変更しないでください。accessible_markets_ids は、ブロックの markets に列挙されたグループに属する市場のIDです。

  3. いくつかのステップで submit_orders(markets) を呼び出します。エージェントは、出したい注文や取り消したい注文を返します（何も返さなくても構いません）。

  4. 市場がそのエージェントの注文を受け付けたとき、取消注文を受け付けたとき、注文を約定させたときに、それぞれ submitted_order、canceled_order、executed_order を呼び出します。

各ステップで、ランナーはランダムな順序でエージェントに問い合わせ、1つ以上の注文を返したエージェントの数が maxNormalOrders （デフォルトは 1。セッション を参照）に達するまで続けます。注文を返さなかったエージェントは数に含まれず、ランナーは次のエージェントに問い合わせます。そのため、多数のエージェントがいるシミュレーションでは、各エージェントが注文を出すのは一部のステップだけです。

エージェントは Agent を継承し、submit_orders を実装する必要があります。コールバックはデフォルトでは何もしません。

パラメータの読み込み¶

MovingAverageAgent は、市場価格を直近 windowSize ステップの平均価格と比較します。パラメータは setup で読み込みます：

window_size: int
order_volume: int
last_orders: Dict[int, Order]  # market ID -> last order placed
n_submitted: int
n_canceled: int
trades: List[Tuple[int, float, int]]  # (step, price, +volume or -volume)

def setup(
    self,
    settings: Dict[str, Any],
    accessible_markets_ids: List[int],
    *args: Any,
    **kwargs: Any,
) -> None:
    """Read the parameters of the agent from its block of the config.

    Args:
        settings (Dict[str, Any]): the agent's block of the config. It must include
            "windowSize" and can include "orderVolume" (default: 1).
        accessible_markets_ids (List[int]): IDs of the markets the agent can trade.
        *args: not used.
        **kwargs: not used.

    """
    super().setup(settings=settings, accessible_markets_ids=accessible_markets_ids)
    json_random = JsonRandom(prng=self.prng)
    self.window_size = int(json_random.random(settings["windowSize"]))
    self.order_volume = int(json_random.random(settings.get("orderVolume", 1)))
    self.last_orders = {}
    self.n_submitted = 0
    self.n_canceled = 0
    self.trades = []

  • super().setup(...) は、すべてのエージェントに必須の cashAmount と assetVolume を読み込み、エージェントに現金と、取引可能な各市場の株式を与えます。

  • ブロックのその他のキーは settings から読み込めます。JsonRandom は、一様乱数を表す [10, 30] など、組み込みエージェントと同じ記法を受け付け（ランダムパラメータ（JsonRandom） を参照）、浮動小数点数を返します。int() は小数部分を切り捨てるため、[10, 30] からは10から29までの窓幅が得られます。

  • エージェントの属性はクラス本体で宣言し、setup で値を設定してください。

  • シミュレーションがシードによって決まるように、エージェントのランダムな選択にはすべて self.prng を使ってください。

注文を出す¶

submit_orders はシミュレーションのすべての市場を受け取り、注文のリストを返します：

def submit_orders(self, markets: List[Market]) -> List[Union[Order, Cancel]]:
    """Decide the orders of this step.

    Args:
        markets (List[Market]): all the markets of the simulation.

    Returns:
        List[Union[Order, Cancel]]: the orders and cancel orders to submit.

    """
    orders: List[Union[Order, Cancel]] = []
    for market in markets:
        if not self.is_market_accessible(market_id=market.market_id):
            continue
        time = market.get_time()
        if time < self.window_size:
            continue
        last_order = self.last_orders.pop(market.market_id, None)
        if last_order is not None and last_order.volume > 0:
            # not fully executed: without ttl, it is still in the order book
            orders.append(Cancel(order=last_order))
        past_prices = market.get_market_prices(
            times=range(time - self.window_size, time)
        )
        moving_average = sum(past_prices) / len(past_prices)
        price = market.get_market_price()
        if price > moving_average:
            is_buy = True
        elif price < moving_average:
            is_buy = False
        else:
            continue
        tick_level = market.convert_to_tick_level(price=price, is_buy=is_buy)
        order = Order(
            agent_id=self.agent_id,
            market_id=market.market_id,
            is_buy=is_buy,
            kind=LIMIT_ORDER,
            volume=self.order_volume,
            price=market.convert_to_price(tick_level=tick_level),
        )
        orders.append(order)
        self.last_orders[market.market_id] = order
    return orders

  • エージェントが取引できない市場は、is_market_accessible で判定してスキップします。

  • 読み出せるのは現在のステップとそれ以前のステップだけです：market.get_market_price() は現在の価格で、get_market_prices(times=...) はそれ以前のステップの価格を返します。

  • すべての注文に agent_id=self.agent_id が必要です：他のエージェントのIDを持つ注文は ValueError: spoofing order is not allowed. please check agent_id in order を発生させます。

  • LIMIT_ORDER には price が必要で、MARKET_ORDER には価格を指定してはいけません（price=None）。volume は正の値でなければなりません。

  • 指値は convert_to_tick_level と convert_to_price でティックサイズに丸めてください。そうしないと、市場が警告を出して丸めます（買い注文は切り下げ、売り注文は切り上げ）。

  • ttl がない注文は、約定するか取り消されるまで板に残ります。ttl=n の場合、注文を出してから n ステップより多く経過すると板から削除されます。

  • 注文を取り消すには、以前に出した Order を指定した Cancel(order=...) を返します。市場は注文が約定するにつれて order.volume を減らすため、ttl のない注文は、volume が正である間は板に残っています。ttl によって削除された注文の volume はそのまま残ります。すでに板にない注文を取り消してもエラーにはなりません。

  • 注文ごとに新しい Order を作成してください：同じオブジェクトを再び出すと ValueError: the order is already submitted が発生します。

  • 1つのエージェントの注文はリストの順に処理されるため、上の取消注文は新しい注文より先に処理されます。

  • 市場は現金や株式を確認しません：エージェントは現金がなくても買うことができ、保有していない株式も売ることができます。モデルに必要であれば、そのような確認を submit_orders に追加してください。

結果の追跡¶

コールバックは、注文がどうなったかをエージェントに知らせます：

def submitted_order(self, log: OrderLog) -> None:
    """Count the orders that a market has accepted.

    Args:
        log (OrderLog): the accepted order.

    """
    self.n_submitted += 1

def executed_order(self, log: ExecutionLog) -> None:
    """Record an execution of one of the agent's orders.

    Args:
        log (ExecutionLog): the execution.

    """
    volume = log.volume if log.buy_agent_id == self.agent_id else -log.volume
    self.trades.append((log.time, log.price, volume))

def canceled_order(self, log: CancelLog) -> None:
    """Count the cancel orders that a market has accepted.

    Args:
        log (CancelLog): the canceled order.

    """
    self.n_canceled += 1

executed_order は、約定の買い手と売り手の両方について、現金と株式が更新された後に呼び出されます。ttl によって失効した注文に対するコールバックはありません。

既存のエージェントの変更¶

組み込みエージェントを変更するには、それを継承し、異なる部分だけをオーバーライドします。FCNAgent は、ファンダメンタリスト、チャーティスト、ノイズの各成分を組み合わせます。チャーティスト成分は、is_chart_following が True （デフォルト）のとき過去のトレンドに追随します。ContrarianFCNAgent はこれを反転させます：

class ContrarianFCNAgent(FCNAgent):
    """FCN agent whose chart term is reversed: it expects past trends to revert."""

    def setup(
        self,
        settings: Dict[str, Any],
        accessible_markets_ids: List[int],
        *args: Any,
        **kwargs: Any,
    ) -> None:
        """Set up the FCN agent, then reverse its chart term.

        Args:
            settings (Dict[str, Any]): the agent's block of the config.
            accessible_markets_ids (List[int]): IDs of the markets the agent can trade.
            *args: not used.
            **kwargs: not used.

        """
        super().setup(settings=settings, accessible_markets_ids=accessible_markets_ids)
        self.is_chart_following = False

エージェントの使用¶

設定では、シミュレーションの実行 の設定に、新しいエージェントのグループを1つずつ追加します：

CONFIG: Dict[str, Any] = {
    "simulation": {
        "markets": ["Market"],
        "agents": ["FCNAgents", "ContrarianAgents", "MovingAverageAgents"],
        "sessions": [
            {
                "sessionName": "warmup",
                "iterationSteps": 100,
                "withOrderPlacement": True,
                "withOrderExecution": False,
                "withPrint": True,
            },
            {
                "sessionName": "main",
                "iterationSteps": 500,
                "withOrderPlacement": True,
                "withOrderExecution": True,
                "withPrint": True,
            },
        ],
    },
    "Market": {"class": "Market", "tickSize": 0.00001, "marketPrice": 300.0},
    "FCNAgents": {
        "class": "FCNAgent",
        "numAgents": 100,
        "markets": ["Market"],
        "assetVolume": 50,
        "cashAmount": 10000,
        "fundamentalWeight": {"expon": [1.0]},
        "chartWeight": {"expon": [0.0]},
        "noiseWeight": {"expon": [1.0]},
        "noiseScale": 0.001,
        "timeWindowSize": [100, 200],
        "orderMargin": [0.0, 0.1],
    },
    "ContrarianAgents": {
        "extends": "FCNAgents",
        "class": "ContrarianFCNAgent",
        "numAgents": 20,
        "chartWeight": {"expon": [1.0]},
    },
    "MovingAverageAgents": {
        "class": "MovingAverageAgent",
        "numAgents": 10,
        "markets": ["Market"],
        "assetVolume": 50,
        "cashAmount": 10000,
        "windowSize": [10, 30],
        "orderVolume": 1,
    },
}

ContrarianAgents は extends で FCNAgents のブロックをコピーし、クラス、エージェント数、chartWeight を変更します（重みが0のとき、チャーティスト成分は何もしません）。MovingAverageAgents は、Agent.setup が必要とするキーと、MovingAverageAgent が読み込むキーを指定します。

main() を呼ぶ前に、新しいクラスをランナーに登録します。ブロックの class には登録したクラスの名前を指定します：

def run_simulation(seed: int) -> SequentialRunner:
    """Register the user-defined agents and run the simulation.

    Args:
        seed (int): seed of the random number generator.

    Returns:
        SequentialRunner: the runner after the run.

    """
    runner = SequentialRunner(settings=CONFIG, prng=random.Random(seed))
    runner.class_register(cls=MovingAverageAgent)
    runner.class_register(cls=ContrarianFCNAgent)
    runner.main()
    return runner


def report(runner: SequentialRunner) -> None:
    """Print what each moving average agent did.

    Args:
        runner (SequentialRunner): the runner after the run.

    """
    market = runner.simulator.name2market["Market"]
    for agent in runner.simulator.agents_group_name2agent["MovingAverageAgents"]:
        if isinstance(agent, MovingAverageAgent):
            print(
                f"{agent.name}: window {agent.window_size}, "
                f"orders {agent.n_submitted}, cancels {agent.n_canceled}, "
                f"trades {len(agent.trades)}, "
                f"shares {agent.get_asset_volume(market_id=market.market_id)}, "
                f"cash {agent.get_cash_amount():.2f}"
            )

移動平均エージェントは warmup では注文を出しません：注文が約定しない間は市場価格が動かないため、市場価格がその平均と等しくなるからです。main では、上で説明したとおり各ステップで注文を出すエージェントは1つだけで、移動平均エージェントはこれらのステップを120体のFCNエージェントと分け合います。より多く取引させるには、セッションの maxNormalOrders を大きくするか、移動平均エージェントを増やしてください。

クラス名は一意でなければなりません：FCNAgent のような組み込みクラスと同じ名前をクラスに付けないでください。詳しくは ユーザー定義クラス を参照してください。

補足¶

  • HighFrequencyAgent を継承したエージェントは高頻度エージェントです。ランナーは、maxHighFrequencyOrders と highFrequencySubmitRate の設定に従い、各通常エージェントの注文の後に高頻度エージェントに問い合わせます（セッション を参照）。

  • MovingAverageAgent は、submit_orders で設定する属性に直前の注文を保持します。これは SequentialRunner とスレッドランナーでは動作しますが、そのような変更が失われるプロセスランナーでは動作しません（並列ランナー を参照）。
