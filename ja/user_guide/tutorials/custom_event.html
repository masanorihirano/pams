イベントや市場の作成¶

イベントは、実行中のシミュレーションを変化させます：組み込みのイベントは、ファンダメンタル価格にショックを与える、注文価格を制限する、売買を停止する、誤った注文を投入するといったことを行います（イベント を参照）。このチュートリアルでは、ニュースのように一定間隔でファンダメンタル価格をランダムに動かすイベントを作成し、その後、市場自体を拡張する方法を示します。完全なスクリプトは tutorial_custom_event.py です。

ランナーによるイベントの扱い¶

イベントは、そのブロックの名前をセッションの events に列挙することでセッションに割り当てられます。ランナーは、列挙された各名前について次のことを行います：

  1. イベントを作成します。その name はブロックの名前、session はイベントを列挙したセッションで、イベントは各自の乱数生成器 prng と simulator を持ちます。

  2. すべての市場とエージェントのセットアップが終わった後、ブロック（extends を解決した後のもの）を渡して setup(settings) を呼び出します。

  3. setup の直後に hook_registration() を呼び出します。これは EventHook のリストを返し、イベントのどのメソッドをいつ呼び出すかをシミュレーターに伝えます。

各フックは hook_type と is_before を持ち、これらによって呼び出されるメソッドが決まります：

hook_type

is_before=True

is_before=False

"order"

hooked_before_order(simulator, order)：市場が注文を受け取る前。イベントはここで Order を変更できます。

hooked_after_order(simulator, order_log)：市場が注文を受け取った後。

"cancel"

hooked_before_cancel(simulator, cancel)

hooked_after_cancel(simulator, cancel_log)

"execution"

使用できません。

hooked_after_execution(simulator, execution_log)：各約定の後。

"session"

hooked_before_session(simulator, session)：セッションの最初のステップの前。

hooked_after_session(simulator, session)：セッションの最後のステップの後。

"market"

hooked_before_step_for_market(simulator, market)：ステップ内でエージェントに注文を問い合わせる前。

hooked_after_step_for_market(simulator, market)：ステップの終わり。

フックの time は、フックが有効になるステップのリストです。セッションのフックでは、セッションの最初のステップ（前）または最後のステップ（後）です。ステップはセッションの開始からではなく、シミュレーションの開始から数えます。time=None （デフォルト）の場合、フックはイベントを列挙したセッションだけでなく、すべての セッションのすべてのステップで有効になります。

"market" フックでは、specific_instance （1つの Market）または specific_class （市場クラス）を指定して、それらの市場に対してだけ呼び出されるようにすることもできます。指定しない場合は、すべての市場に対して呼び出されます。

イベント¶

NewsShock は、セッション中の interval ステップごとに、target 市場のファンダメンタル価格を \(e^{x}\) 倍します。ここで \(x\) は、平均0、標準偏差 jumpScale の正規分布から生成されます：

class NewsShock(EventABC):
    """Random news that moves the fundamental price of one market at regular intervals.

    Every ``interval`` steps of its session, the fundamental price of the ``target``
    market is multiplied by :math:`e^{x}`, where :math:`x` is drawn from a normal
    distribution with mean 0 and standard deviation ``jumpScale``.
    """

    target_market: Market
    interval: int
    jump_scale: float
    news_times: List[int]

    def setup(self, settings: Dict[str, Any], *args: Any, **kwargs: Any) -> None:
        """Read the parameters of the event from its block of the config.

        Args:
            settings (Dict[str, Any]): the event's block of the config. It must include
                "target" (the name of a market), "interval" and "jumpScale".
            *args: not used.
            **kwargs: not used.

        """
        for key in ["target", "interval", "jumpScale"]:
            if key not in settings:
                raise ValueError(f"{key} is required for NewsShock")
        self.target_market = self.simulator.name2market[settings["target"]]
        self.interval = int(settings["interval"])
        self.jump_scale = float(settings["jumpScale"])
        self.news_times = []

    def hook_registration(self) -> List[EventHook]:
        """Tell the simulator when to call this event.

        Returns:
            List[EventHook]: a hook before the market step at every news time, and a
            hook after the session of the event.

        """
        start = self.session.session_start_time
        end = start + self.session.iteration_steps
        news_hook = EventHook(
            event=self,
            hook_type="market",
            is_before=True,
            time=list(range(start + self.interval, end, self.interval)),
            specific_instance=self.target_market,
        )
        session_hook = EventHook(
            event=self, hook_type="session", is_before=False, time=[end - 1]
        )
        return [news_hook, session_hook]

    def hooked_before_step_for_market(
        self, simulator: Simulator, market: Market
    ) -> None:
        """Change the fundamental price before the market step.

        Args:
            simulator (Simulator): the simulator.
            market (Market): the target market.

        """
        jump = self.prng.gauss(0.0, self.jump_scale)
        market.change_fundamental_price(scale=math.exp(jump))
        self.news_times.append(market.get_time())

    def hooked_after_session(self, simulator: Simulator, session: Session) -> None:
        """Print a summary at the end of the session of the event.

        Args:
            simulator (Simulator): the simulator.
            session (Session): the session that has just ended.

        """
        print(
            f"{self.name}: {len(self.news_times)} news in {session.name}, "
            f"fundamental price {self.target_market.get_fundamental_price():.2f}"
        )

  • setup はブロックのキーを確認して読み込みます。市場はすでに存在するため、self.simulator.name2market で対象の市場を検索できます。

  • hook_registration は、self.session を使ってフックを自身のセッション内に限定します：ニュースのフックは、セッションの終わりより前のステップ start + interval、start + 2 * interval、... で、対象の市場に対してだけ有効になります。セッションのフックは、セッションの最後のステップで有効になります。time=None とすると、セッションのフックは warmup セッションの後にも呼び出されてしまいます。

  • change_fundamental_price は、エージェントに注文を問い合わせる前に、現在のステップのファンダメンタル価格を変更します。この変化は恒久的です：ファンダメンタル価格は新しい水準にとどまるか、市場に fundamentalVolatility がある場合はその水準からランダムウォークを続けます。

  • イベントは乱数を self.prng から生成するため、シミュレーションはシードによって決まったままです。

イベントの使用¶

main セッションがイベントを列挙し、ブロックでそのクラスとパラメータを指定します。それ以外は シミュレーションの実行 の設定と同じです：

CONFIG: Dict[str, Any] = {
    "simulation": {
        "markets": ["Market"],
        "agents": ["FCNAgents"],
        "sessions": [
            {
                "sessionName": "warmup",
                "iterationSteps": 100,
                "withOrderPlacement": True,
                "withOrderExecution": False,
                "withPrint": True,
            },
            {
                "sessionName": "main",
                "iterationSteps": 500,
                "withOrderPlacement": True,
                "withOrderExecution": True,
                "withPrint": True,
                "events": ["News"],
            },
        ],
    },
    "News": {
        "class": "NewsShock",
        "target": "Market",
        "interval": 50,
        "jumpScale": 0.02,
    },
    "Market": {"class": "Market", "tickSize": 0.00001, "marketPrice": 300.0},
    "FCNAgents": {
        "class": "FCNAgent",
        "numAgents": 100,
        "markets": ["Market"],
        "assetVolume": 50,
        "cashAmount": 10000,
        "fundamentalWeight": {"expon": [1.0]},
        "chartWeight": {"expon": [0.0]},
        "noiseWeight": {"expon": [1.0]},
        "noiseScale": 0.001,
        "timeWindowSize": [100, 200],
        "orderMargin": [0.0, 0.1],
    },
}

エージェントと同様に、main() を呼ぶ前にクラスをランナーに登録します：

def run_simulation(seed: int) -> SequentialRunner:
    """Register the event class and run the simulation.

    Args:
        seed (int): seed of the random number generator.

    Returns:
        SequentialRunner: the runner after the run.

    """
    runner = SequentialRunner(settings=CONFIG, prng=random.Random(seed))
    runner.class_register(cls=NewsShock)
    runner.main()
    return runner

実行後、runner.simulator.name2event["News"] がこのイベントです。完全なスクリプトを実行すると、main の終わりにイベントの概要を、次に main() の2行の時間を出力し、その後、各ニュースの前後のファンダメンタル価格を出力します：

News: 9 news in main, fundamental price 291.61
# INITIALIZATION TIME 0.005436
# EXECUTION TIME 0.1829801
step 150: 300.00 -> 295.17
step 200: 295.17 -> 302.24
step 250: 302.24 -> 301.98
step 300: 301.98 -> 294.94
step 350: 294.94 -> 298.95
step 400: 298.95 -> 298.90
step 450: 298.90 -> 292.69
step 500: 292.69 -> 286.11
step 550: 286.11 -> 291.61

main セッションはステップ100から始まるため、最初のニュースはステップ150です。

市場の作成¶

市場も同じように拡張します：Market を継承し、super().setup を呼び出して、ブロックから独自のキーを読み込みます。samples/market_share は次の市場を使います：

class ExtendedMarket(Market):
    def setup(self, settings: Dict[str, Any], *args, **kwargs) -> None:  # type: ignore  # NOQA
        super().setup(settings, *args, **kwargs)
        if "tradeVolume" in settings:
            if not isinstance(settings["tradeVolume"], int):
                raise ValueError("tradeVolume must be int")
            self._executed_volumes = [int(settings["tradeVolume"])]

この市場は、キー tradeVolume からステップ0の出来高を設定します。このサンプルでは、MarketShareFCNAgent が各注文の市場を、timeWindowSize ステップ前以降に各市場で取引された出来高で重み付けしてランダムに選ぶため、tradeVolume が初期の市場シェアを決めます。サンプルは runner.class_register(cls=ExtendedMarket) でクラスを登録し、その設定ファイルでは市場のブロックに "class": "ExtendedMarket" を指定しています。
